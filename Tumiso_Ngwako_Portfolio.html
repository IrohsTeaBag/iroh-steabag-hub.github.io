About

I am a cybersecurity intern with a primary focus on web application security. My work involves testing for SQL injection, XSS, access-control flaws, and API security using Burp Suite, following a structured recon-to-report methodology.

I also build threat detection workflows with SIEM tools like Wazuh and Microsoft Sentinel, and have deployed a honeypot on Azure to study real-world attack traffic alongside EDR tooling.

In addition, I have hands-on experience in OT and industrial control systems security, including Siemens S7-1200 PLCs and SCADA protocols — a secondary area that supports my primary work in web and cloud security.
